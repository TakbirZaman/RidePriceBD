# RidePriceBD

Know your fare before you ride in Dhaka. Rickshaw, bike, car, CNG, bus — with ML breakdown.

What it does:
- Fare estimate for 76 Dhaka locations
- Rush hour / late night / rain adjustments
- Shows why the price is what it is

Stack: Python (Flask + sklearn), plain HTML/JS

Run it:
```bash
pip install -r requirements.txt
python api.py
# or just open index.html for frontend only
```
Live: https://ridepricebd.netlify.app
